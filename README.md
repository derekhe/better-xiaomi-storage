# Better Xiaomi Storage（拾光）

一个面向小米智能存储的开源、只读 Windows 相册。它为大型照片库提供时间轴、相册导航、年月日快速定位、搜索、媒体筛选、懒加载缩略图和大图预览。

![拾光相册设计预览](docs/design/gallery-concept.png)

## 主要功能

- 按拍摄日期浏览照片时间轴。
- 直接选择年、月、日，快速跳到很久以前的照片。
- 按相册、关键字和照片/视频类型筛选。
- 点击照片查看适应窗口的原图；点击视频使用原生播放器播放和拖动进度。
- 先读取轻量照片索引，再按需加载目标附近的缩略图，适合大型照片库。
- 只读访问，不提供删除、上传或修改设备内容的功能。

## 安装与使用

系统要求：Windows 10/11，以及已经安装并能正常使用的官方“小米智能存储”客户端。

1. 从 [Releases](https://github.com/derekhe/better-xiaomi-storage/releases) 下载最新的 `better-xiaomi-storage-*-setup.exe`。
2. 运行安装程序。当前安装包未进行商业代码签名，Windows SmartScreen 可能显示“未知发布者”；请只从本仓库 Release 下载，并按下方方法核对 SHA-256。
3. 打开并登录官方小米智能存储客户端，确认设备在线，再进入一次官方相册以建立本机通道。
4. 启动“拾光”。首次连接会读取完整的轻量照片索引，照片很多时需要稍等片刻。
5. 点击顶部的时间定位，依次选择年份、月份和日期，即可跳转到对应位置。

校验安装包（将文件名替换为实际版本）：

```powershell
Get-FileHash .\better-xiaomi-storage-0.1.0-setup.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

两处哈希值必须完全一致。

## 常见问题

- 提示“尚未找到设备证书”：先登录官方客户端，并确认当前 Windows 用户能够正常查看相册。
- 提示“未找到设备通道”或“设备通道当前不可用”：保持官方客户端运行，进入一次官方相册后，在拾光中点击重连。
- 时间定位首次加载较慢：应用正在获取轻量索引，不会同时下载全部缩略图；之后定位只加载目标附近内容。
- SmartScreen 警告：0.1.0 尚未代码签名。请只使用 GitHub Release 中的文件并验证 SHA-256。

## 隐私与安全边界

- 应用只调用相册列表、照片列表和缩略图等读取接口，不上传、删除或修改设备文件。
- 官方客户端仍负责小米账号登录、证书签发和 P2P 通道；本项目不实现小米账号登录。
- 应用使用本机官方客户端生成的客户端证书和私钥连接 `127.0.0.1` 通道。密钥只由 Electron 主进程读取，不会复制到项目、页面或网络服务。
- 原图和视频通过官方客户端建立的本机 WebDAV 隧道按需读取；临时用户名和密码仅保存在 Electron 主进程内存中，不会传给页面或写入日志。
- 连接探测会调用官方客户端的 `get_access_token` 接口，并且只检查返回结果中是否存在令牌以确认通道有效；令牌不会被保存、记录、转发或用于后续请求。
- 应用不读取或复制官方客户端的 Cookie、账号密码。
- 页面启用上下文隔离、禁用 Node 集成，并通过受限 IPC 接口访问本机设备通道。

本仓库不包含任何用户证书、私钥、令牌、设备 ID、照片或运行日志。若需要完全摆脱官方客户端，还需另行实现小米 SSO、证书生命周期和原生 P2P 通道，这不属于当前版本范围。

## 开发

需要 Node.js 20 或更高版本。

```powershell
npm ci
npm run dev
```

单独查看界面可运行 `npm run dev:web`，此时使用不含个人信息的样例数据。

```powershell
npm test
npm run build
npm run package
```

网页产物位于 `dist/renderer`，Windows 安装包位于 `release`；两者都不会提交到 Git。

维护者发布前应执行测试、构建、依赖与凭据扫描，并确认安装包中的 `app.asar` 只包含运行所需文件。
